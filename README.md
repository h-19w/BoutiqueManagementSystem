### Boutique Management System (final project)

Java project. Open the folder in VS Code and install the recommended **Extension Pack for Java** when prompted, then run any file with a `main` method via **Run ▶**.

Requires MySQL Connector/J — put `mysql-connector-j-8.4.0.jar` in `lib/` and a local MySQL/WAMP server (see `Database.java`).
